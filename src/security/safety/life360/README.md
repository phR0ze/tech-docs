## Overview

### Comparison with Microsoft Family Safety
[Microsoft Family Safety](https://www.microsoft.com/en-us/microsoft-365/family-safety) is a
parental control and family organization app bundled with Microsoft 365. It originally offered
its own location sharing and driving-safety features, but Microsoft discontinued both on
November 29, 2024, leaving screen time and content filtering as its core focus.

| Feature            | Life360                        | Microsoft Family Safety   |
| ------------------ | ------------------------------ | ------------------------- |
| Location sharing   | ✓ `Circles`                    | ✗ Discontinued Nov 2024   |
| Place alerts       | ✓ `Places`, arrival/departures | ✗ Discontinued Nov 2024   |
| Driving reports    | ✓ Free + paid tiers            | ✗ Discontinued Nov 2024   |
| Crash detection    | ✓ Paid tiers                   | ✗                         |
| SOS / emergency    | ✓ SOS + PIN                    | ✗                         |
| Screen time        | ✗                              | ✓ Per app/device          |
| Content filtering  | ✗                              | ✓ Via Edge                |
| Spending controls  | ✗                              | ✓ MS account limits       |
| Focus              | Location + driving             | Device usage + content    |
| Pricing            | Free + paid tiers              | Bundled w/ M365 Family    |

**Takeaway** — the two apps are largely complementary rather than competing: Life360 covers
location, driving, and emergency safety, while Family Safety covers screen time and content
filtering. Since Family Safety no longer offers location tracking, families wanting that
capability need Life360 (or a similar app) regardless of whether they also use Family Safety
for screen time management.

### Comparison with HeyPolo, GeoZilla and FamiSafe
[HeyPolo](https://heypolo.com/), [GeoZilla](https://geozilla.com/) and [FamiSafe](https://www.famisafe.com/)
are the closest direct competitors to Life360 in the family location-tracking space, each taking
a different angle: HeyPolo leads with privacy-first, consent-based sharing (built by the team
behind the Surfshark VPN), GeoZilla most closely mirrors Life360's own feature set, and FamiSafe
leans further into parental-control territory with screen time and content filtering alongside
location.

| Feature              | Life360             | HeyPolo               | GeoZilla                | FamiSafe             |
| -------------------- | ------------------- | --------------------- | ----------------------- | -------------------- |
| Location sharing     | ✓ `Circles`         | ✓ Opt-in per share    | ✓ Family circles        | ✓ Geofenced zones    |
| Sharing model        | Always-on           | Consent-based         | Always-on               | Parent-managed       |
| Driving reports      | ✓ Free + paid tiers | ✓ Teen speed only     | ✓ Speed, braking, phone | ✓ Speed, route, time |
| Crash detection      | ✓ Paid tiers        | ✗                     | ✓                       | ✗                    |
| SOS / emergency      | ✓ SOS + PIN         | ✓ Emergency button    | ✓                       | ✗                    |
| Screen time          | ✗                   | ✗                     | ✗                       | ✓ Per app/device     |
| Content filtering    | ✗                   | ✗                     | ✗                       | ✓ Category-based     |
| Sells 3rd-party data | Criticized for it   | ✗ Never               | Not stated              | Not stated           |
| Focus                | Location + driving  | Privacy-first sharing | Location + driving      | Parental controls    |
| Pricing              | Free + paid tiers   | Free + premium        | Free + premium          | From ~$10/mo         |

**Takeaway** — pick based on priority: HeyPolo if location-data privacy is the primary concern,
GeoZilla for a near feature-for-feature Life360 alternative, and FamiSafe if you also need
screen time and content filtering alongside location tracking (overlapping with what Microsoft
Family Safety used to offer, see [above](#comparison-with-microsoft-family-safety)).
